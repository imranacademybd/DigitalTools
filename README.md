# DigitalTools Blog

Static blog starter for GitHub Pages.

## Files
- `index.html` — homepage
- `article.html` — sample article
- `about.html` — about page
- `style.css` — responsive design
- `script.js` — mobile menu

## GitHub Pages
Upload these files to the `main` branch of your repository. Then enable GitHub Pages from:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

If the repository is `imranacademybd/DigitalTools`, the default Pages address will be:
https://imranacademybd.github.io/DigitalTools/
